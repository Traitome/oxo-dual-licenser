## [0.1.0] - 2026-04-05

### Features

- Initial release of `oxo-license` library with Ed25519 license verification
- Initial release of `oxo-license-issuer` CLI tool
- Support for arbitrary license types (academic, commercial, enterprise, etc.)
- Configurable schema version, public key, and file discovery paths
- `LicenseConfig` struct for per-project configuration
- `generate-keypair`, `issue`, and `verify` subcommands in CLI
- Comprehensive test suite with 14 unit tests
